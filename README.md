# Magnetic Scanner Studio

Тёмное desktop-приложение для Ubuntu, предназначенное для управления 3D-принтером Ender 3 и магнитным датчиком MLX90393.

## Как изучать проект

Читайте файлы именно в этом порядке — каждый следующий слой использует
предыдущий:

1. `config.py` — все числа, которые описывают реальное оборудование:
   порт, размеры стола, смещение датчика, скорости и адрес I²C.
2. `printer.py` — низкоуровневый обмен с Marlin по USB: как отправляются
   `G28`, `G1`, `M114`, `M17`, `M84`, `M112` и `M999`.
3. `sensor.py` — создание MLX90393, усреднение измерений и вычитание фона.
4. `scanner.py` — математика траекторий, перевод координат датчика в
   координаты сопла и сам цикл измерения точки за точкой.
5. `csv_export.py` и `storage.py` — сохранение одного завершённого скана в
   CSV и SQLite-архив соответственно.
6. `desktop_app.py` — Qt-окно, фоновый поток оборудования и мост Python ↔ UI.
7. `ui/native.qss` — только нативная шапка frameless-окна Qt.
8. `ui/studio.html` — интерфейс: сначала HTML-разметка, затем CSS, в конце
   JavaScript-объект `NexusApp`, который получает события из Python.
9. `tests/` — безопасные проверки без принтера и датчика. Они хорошо
   показывают ожидаемое поведение критической логики.

В исходниках русскими комментариями отмечены назначение модулей, опасные
места с потоками, формат данных Python ↔ JavaScript, формулы координат и
причины ограничений. Комментарии написаны к смысловым действиям, а не к
скобкам и CSS-свойствам: это позволяет читать код, а не пролистывать шум.

## Запуск

```bash
source env/bin/activate
python -m pip install -r requirements.txt
python desktop_app.py
```

Интерфейс запускается в Qt WebEngine: HTML/CSS/JavaScript находятся в
`ui/studio.html`, а нативная шапка окна оформлена в `ui/native.qss`.

Настройки порта, геометрии стола и датчика находятся в `config.py`.

Доступны подключение устройств, G28, M17/M84, аварийная остановка M112,
калибровка нуля, CSV и SQLite-архив. Режимы сканирования: змейка, окружность
для цилиндра и заданная прямая для магнитной системы.

## Проверка после изменений

```bash
python -m unittest discover -s tests -v
python -m py_compile desktop_app.py printer.py sensor.py scanner.py
```

Тесты не открывают USB-порт и не отправляют команды принтеру. Они проверяют
траектории, разбор `M114` и безопасную последовательность `M112 → M999`.
