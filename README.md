# Magnetic Scanner Studio

Тёмное desktop-приложение для Ubuntu, предназначенное для управления 3D-принтером Ender 3 и магнитным датчиком MLX90393.

## Запуск

```bash
source env/bin/activate
python -m pip install -r requirements.txt
python desktop_app.py
```

Приложение не загружает тяжёлый HTML/Plotly-движок при старте: управление
принтером и датчиком остаётся быстрым даже на Raspberry Pi. Графики и карта
будут подключены после проверки рабочего цикла сканирования.

Настройки порта, геометрии стола и датчика находятся в `config.py`.

Доступны подключение устройств, возврат домой (`G28`), отключение двигателей
(`M84`), аварийная остановка (`M112`), калибровка нуля, контрольное измерение
и настоящее сканирование с сохранением CSV. Перед запуском сканирования
приложение покажет подтверждение, затем откалибрует датчик и выполнит G28.
